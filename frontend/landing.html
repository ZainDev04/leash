What it stops

Mistakes and tricks
an agent can fall for.

Each payment on the dashboard shows which check fired and the reason in plain English.

  • Hidden instructions on a shop page

    A page tells AI assistants to also buy a $90 gift card. Gemini flags it and Leash releases the hold.

  • A price that rises at checkout

    The quote said $19 and checkout says $29. Code blocks it before PayPal is called.

  • The same purchase twice

    An agent retries and tries to buy the same item again within 10 minutes. Code blocks the repeat.

  • Stores and categories you did not allow

    Anything outside your lists is blocked, and so is any payment over your limit or monthly budget.

  • Big purchases

    Above your "ask me first" amount, the money stays on hold until you approve or reject it.

  • An agent that goes wrong

    The kill switch freezes every agent at once. Agents have no way to turn it off or approve their own payments.

Connect an agent

Add Leash to Claude
with one command.

Leash ships an MCP server with tools to read a shop page, pay and check the budget. Other agents can call the HTTP API with an API key.

claude mcp add leash -e LEASH_API_KEY=your-agent-key -- /path/to/leash/.venv/Scripts/python /path/to/leash/mcp_server/server.py

Setup steps for Claude Code and Claude Desktop are in the README.

Questions

Common questions

Does Leash move real money?

No. Leash runs on the PayPal sandbox, which uses test accounts. It is a working prototype built for the PayPal AI Hackathon 2026.

Can an agent approve its own payment?

No. An agent holds an API key that only reaches the pay and read endpoints. Approving, changing rules and lifting the freeze need the dashboard login.

What happens if the AI or PayPal fails?

The payment is blocked and nothing is taken. The AI can only make a decision stricter, so it can never approve something your rules refuse.

Can Leash catch an agent that lies?

For stores on your verified list, Leash reads the page itself and compares the price and seller with what the agent claims. A payment without a page Leash could read waits for you. Try it on the demo store.

Which agents can use it?

Any MCP client, such as Claude Code, or any program that can send an HTTP request with an API key.
